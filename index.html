What needs to happen before this works

This tab is the interface foundation, not a claim that the social features are already live.

  1. Run the supplied Supabase SQL setup to create the social tables and row-level security policies.
  2. Connect friend invitations, room membership, chat and reminders to Supabase Realtime.
  3. Configure WebRTC signaling and a TURN relay for dependable screen sharing across networks.
Your existing habits, XP, goals and Pomodoro data are not changed by this addition.
